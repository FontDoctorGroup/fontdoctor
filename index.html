Abstract

Chinese characters are not only a medium for the transmission of Chinese culture but also a visual manifestation of Eastern aesthetics. Despite rising demand for diverse fonts, production remains constrained by inefficient manual quality control across many characters and complex workflows. To address the need for Chinese font quality inspection, this paper introduces FontDoctor, a multimodal large model for intelligent defect detection and labeling in Chinese fonts. FontDoctor features two complementary defect detection paradigms: few-shot template-referenced and non-referenced universal approaches. To effectively integrate defect detection into MLLM, we establish a semantic mapping between raster images of Chinese characters and vector data using SVG XML, allowing the model to accurately locate and label font defects by understanding SVG files. To overcome the contextual bottleneck caused by multiple templates, we convert the discrete SVG XML character stream into dense visual embeddings, enabling the MLLM's visual encoder to combine both semantic understanding and data compression, achieving highly compact feature representations. We introduce CFDefect-2M, a 2M-character dataset for font defect detection. To our knowledge, this is among the first studies on Chinese font defect detection. Experiments show that FontDoctor achieves state-of-the-art performance and shows strong potential for integration into professional workflows.

Model Architecture

Overview of FontDoctor. We encode Bezier-based glyphs into SVG XML as an intermediate modality bridging visual and topological semantics, enabling precise defect localization within the MLLM framework. To mitigate the sequence overhead introduced by multiple reference templates, we employ SVG optical compression to significantly reduce token length. The model flexibly supports both few-shot template-referenced and non-referenced universal modes, utilizing sequence concatenation ($\|$) to seamlessly toggle between these configurations.
